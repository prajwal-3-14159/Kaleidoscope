ジュリア集合

マンデルブロ平面のどの点にも、それぞれ専用のジュリア集合があります。まったく同じルールから生まれる、それぞれ異なる図形です。これらをあわせて眺めると、フラクタルという分野でもとりわけ美しい発想の 1 つであることがわかります。

ジュリア集合とは

マンデルブロ集合では、ゲームをいつも 0 から始めて、どんな定数 c なら数が有界にとどまるかを調べました。ジュリア集合は、この見方を裏返します。定数 c を 1 つ選んで固定し、同じルールのもとで、どの出発点 z0 が有界にとどまるかを調べるのです。

zn+1=zn2+c

テキスト表記：z → z² + c（c は固定、出発点 z₀ はさまざま）

脱出しない出発点の集まりを、充填ジュリア集合といいます。その縁がジュリア集合そのものです。縁の外側はすべてファトゥ集合に属します。ここでは、隣り合う出発点がどれも似た振る舞いをします。すべて脱出するか、すべて同じ周期的なサイクルへ渦を巻いて近づくかのどちらかです。c が変わるたびに別の図形になるので、この平面には、点の数だけジュリア集合があるギャラリーが広がっています。わかりやすい例が 2 つあります。c=0 のとき、ジュリア集合は単位円になります。c=−2 のときは、-2 から 2 までの線分になります。

簡単な歴史

ガストン・ジュリアは 25 歳だった 1918 年に、関数の反復についての長大な論文を発表し、フランス科学アカデミーの大賞を受賞しました。同じ問題には、ピエール・ファトゥも独立に取り組んでいました。二人が紙と鉛筆で導いた結果は、これらの集合をみごとなまでに詳しく記述していましたが、実際にその姿を目で見た人はいませんでした。この分野は数十年のあいだ忘れられ、1970 年代後半から 1980 年代にコンピューターによってよみがえりました。ブノワ・マンデルブロの描いた図が、それを広く知らしめたのです。

1 つの定理がギャラリーを整理する

ファトゥ＝ジュリアの二分定理によれば、z2+c のジュリア集合は、1 つにつながった図形か、無限個のばらばらの粒の雲かのどちらかです。後者はカントールの塵と呼ばれます。その中間はありません。つながっているのは、まさに c がマンデルブロ集合に属するときです。そのため、マンデルブロ集合は連結性の軌跡（connectedness locus）とも呼ばれます。どのジュリア集合が 1 つにつながっているかを示す地図、というわけです。

その理由は、臨界点 0 の行く末にあります。0 の軌道が無限大へ脱出すれば、ジュリア集合は塵となって砕け、有界にとどまれば、ジュリア集合はひとつにまとまります。

ギャラリー

ドゥアディのウサギ

マンデルブロ集合の周期 3 のバルブの内側、c≈−0.123+0.745i では、ジュリア集合に 3 方向の耳が生えます。名前はアドリアン・ドゥアディにちなんでいます。この 3 方向の形は、もとになった周期 3 のバルブと対応しています。

ウサギを開く

デンドライト（樹状集合）

c=i のジュリア集合は、輪も内部もない、枝分かれした糸の木です。すべての点が境界の上にあります。この c は、マンデルブロ集合の上端にあるミシュレヴィチ点です。0 の軌道は 0→i→−1+i→−i→−1+i→… と進み、そのあとは 2 ステップのサイクルをいつまでも繰り返します。

デンドライトを開く

ジーゲル円板

主カージオイドの縁にある c≈−0.390541−0.586788i では、不動点の回転数が黄金比の小数部分、約 0.618 に等しくなります。1 ステップごとに、近くの点が 1 回転のその割合だけ回るということです。これらの点は、脱出することも落ち着くこともなく、ジーゲル円板の中をいつまでも周回します。カール・ルートヴィヒ・ジーゲルは 1942 年に、回転数が分数ではうまく近似できないときにこうした円板が存在することを証明しました。黄金比は、その典型的な例です。

ジーゲル円板を開く

サン・マルコ

c=−34 では、主カージオイドと周期 2 の円盤が接しています。ここのジュリア集合は、数えきれないほどの点でくびれており、ヴェネツィアのサン・マルコ大聖堂と広場に似ているといわれることから、サン・マルコ・フラクタルの愛称で呼ばれています。

サン・マルコを開く

カントールの塵

マンデルブロ集合の外側から c を選んでみましょう。たとえば c=0.3+0.6i です。するとジュリア集合は、無限個のばらばらの粒に砕け散ります。

塵を開く

1 枚の絵の表と裏

この 2 種類の図は、深く結びついています。マンデルブロ集合の境界上の点 c の近くを拡大していくと、見える景色は、同じ c のジュリア集合に似てきます。これをミシュレヴィチ点について証明したのが、1990 年のタン・レイ氏（Tan Lei）です。ジュリア集合が、ポインターの下に何があるかを知るのにうってつけのプレビューになるのは、そのためです。

エクスプローラーで見る

試してみましょう：マンデルブロ系のフラクタルで、点にカーソルを合わせると、その点のジュリア集合が小さなピクチャ・イン・ピクチャのウィンドウに表示されます。J キーを押すと、全画面で開きます。コントロールパネルでジュリア集合モードをオンにすると、実部 (Re c) と虚部 (Im c) を自分で入力できます。

バーニングシップ、トライコーン、ケルト、バッファローにも、それぞれジュリア集合版があります。まずはバーニングシップから始めるか、マンデルブロ集合に戻ってみましょう。
