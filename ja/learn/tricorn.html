トライコーン（マンデルバー）

2 乗する前に、数を実軸に関して裏返します。すると、おなじみのマンデルブロ集合のハート形は、3 つの角をもつ三角帽、トライコーンに変わります。

ルール

トライコーンは、マンデルブロ集合のレシピを、バーニングシップとは別の方法で変えたものです。数を折りたたむ代わりに、裏返します。2 乗する前に、z を複素共役に置き換えるのです。複素共役とは、数を実軸に関して鏡に映した数で、虚部の符号が反転します。

zn+1=z¯n2+c

テキスト表記：z → conj(z)² + c

実数の座標で、z=x+iy および c=a+ib と書くと、1 ステップは次のようになります。

xn+1=xn2−yn2+a,yn+1=−2xnyn+b

テキスト表記：x' = x² − y² + a, y' = −2xy + b

マンデルブロ集合のルールとの違いは、2xy の前にあるマイナス記号だけです。この符号 1 つで、おなじみのハート形とバルブは、腕が 3 本、角が 3 つの形に変わります。これが「トライコーン」、つまり三角帽です。

簡単な歴史

この集合は 1989 年に W. D. Crowe、R. Hasson、P. J. Rippon、P. E. D. Strain-Clark によって研究され、マンデルバー集合と名づけられました。のちにジョン・ミルナーが、実 3 次多項式の研究の中でこの集合に再び出会い、トライコーンという名前をつけました。現在は、どちらの名前も使われています。

角が 3 つになる理由

共役をとると回転の向きが逆になるため、トライコーンのルールの 1 ステップは、通常の「解析的」な写像ではありません。マンデルブロ集合に使われるいつもの理論は、そのままでは通用しないのです。ただ、うまい工夫で話の一部を救えます。ルールを2 回適用すると、2 回の共役が打ち消し合います。その結果は、4 次の普通の多項式になります。

z↦(z2+c¯)2+c

テキスト表記：z → (z² + conj(c))² + c （2 ステップ分を合成）

平面を 3 分の 1 回転（120°）させると、c は同じ図形を与える別のパラメータに移ります。3 回対称性は、ここから生まれます。トライコーンは実軸に関して鏡映対称でもあるので、全体としては、反転と回転を組み合わせた 6 通りのどの操作をしても同じに見えます。これは正三角形の対称性です。

どこに注目するか

  • 3 本の腕。120 度ずつ離れて伸び、それぞれの先に小さな丸いバルブがあります。1 本は負の実軸に沿っています。
  • バルブととげ。本体の縁からぶら下がり、3 方向のパターンを繰り返しています。
  • 全体の形の小さなコピー。傾いたり引き伸ばされたりして、より深いところにあります。縁のまわりをズームして探してみてください。
  • 実軸。実数の共役は何も変えないので、実軸の上では、トライコーンとマンデルブロ集合は一致します。

マンデルブロ集合と同じく、トライコーンは、ジュリア集合が連結になるパラメータ c の集合です。ある c がどちら側に入るかは、臨界点 0 の軌道によって決まります。

指数を変えることもできます。z↦z¯d+c で d が整数のとき、図形は (d+1) 回の回転対称性を持ちます。こうした図形はマルチコーン（multicorn）と呼ばれます。パネルの形状セクションでべき乗を設定して、ぜひ確かめてみてください。

トライコーンのジュリア集合

マンデルブロ集合と同じように、c を固定して出発点を変えると、ジュリア集合が得られます。これは c=−0.48+0.52i の場合です。
