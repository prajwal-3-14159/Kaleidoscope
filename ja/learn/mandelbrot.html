マンデルブロ集合

数学で最も有名な図形は、たった 1 行の計算から生まれます。数を 2 乗して定数を足し、それを繰り返すだけです。この集合とは何か、どこから来たのか、拡大するときにどこを見ればよいのかをご紹介します。

マンデルブロ集合とは

平らな紙の上の 1 点を選び、それを複素数 c とみなします。複素数とは 2 つの部分からなる数で、左右の位置が実部、上下の位置が虚部にあたります。ここで簡単なゲームをしてみましょう。z=0 から始めて、次の 1 ステップを何度も繰り返します。今ある数を 2 乗して、c を足すのです。

zn+1=zn2+c

テキスト表記：z → z² + c（z = 0 から開始）

c の値によっては、数はいつまでも小さいままです。逆に、限りなく大きくなって無限大へ「脱出」することもあります。マンデルブロ集合とは、数が一度も脱出しないような c をすべて集めたものです。エクスプローラーでは、これが黒い領域として表示され、そのまわりの色は、ほかの点がどれだけ速く脱出するかを表しています。

c=0 で試してみましょう。数は 0 のままなので、0 は集合に含まれます。c=1 では 0, 1, 2, 5, 26, 677, … となって爆発的に増えるので、1 は集合の外です。c=−1 では 0, -1, 0, -1, … といつまでも繰り返すので、-1 は集合に含まれます。

集合全体は半径 2 の円の内側に収まっていて、数がいったんこの円の外へ出ると、二度と戻ってきません。そのためプログラムは、点が円を出るまでに何ステップかかるかを数えるだけで済みます。この回数、つまり脱出時間が、色として表示されているものです（エクスプローラーのしくみを参照）。

簡単な歴史

z→z2+c というルールそのものは古くからあります。ピエール・ファトゥとガストン・ジュリアが、1918 年ごろに紙と鉛筆で研究しました（ジュリア集合を参照）。図として目に見えるようになったのは、もっと後のことです。ロバート・ブルックス（Robert Brooks）とピーター・マテルスキ（Peter Matelski）の論文（1978 年に執筆、1981 年に発表）に、粗いコンピューター描画が載りました。1980 年には、IBM で研究していたブノワ・マンデルブロが、最初の精密な画像を作りました。彼は 1975 年に「フラクタル」という言葉を生み出していました。

1980 年代の前半に、アドリアン・ドゥアディとジョン・ハバードが、この集合に確かな数学的土台を与えました。二人は、この集合が連結であること、つまり離れ小島のない 1 つながりの図形であることを証明し、マンデルブロにちなんで名前をつけました。1986 年に出版されたパイトゲンとリヒターの著書『フラクタルの美』（原題 The Beauty of Fractals）によって、この集合は広く知られるようになりました。

図の読み方

大きなハート形の本体が主カージオイドです。この内側にあるどの c でも、数はただ 1 つの値に落ち着きます。左側の大きな円盤は周期 2 のバルブで、ここでは数が 2 つの値を交互にとるようになります。これより小さいバルブにもそれぞれ固有の周期（3, 4, 5, …）があります。バルブから伸びる小さなアンテナの枝の本数を数えると、その周期が読み取れます。

外側にある色の帯は、脱出の速さを表す等高線で、境界に近づくほど間隔が詰まっていきます。この境界はとても入り組んでいて、ハウスドルフ次元は 2 になります。平面上の曲線としては、これ以上ないほど複雑だということです（宍倉光広氏、1998 年）。

水平な軸（実軸）に沿って、集合は c=−2 から c=14 まで伸びています。カージオイドの尖点から左へたどっていくと、数が落ち着く先の値は c=−34 で 2 つに分かれ、続いて 4 つ、8 つと分かれていきます。分岐は次第に速く起こり、c≈−1.4012 のあたりに積み重なって、そこからカオスが始まります。連続する分岐の間隔の比、約 4.669 は、ファイゲンバウム定数と呼ばれます。

ミニ・マンデルブロ

左へ伸びる細い棘の上、c≈−1.7549 のところに、集合全体の小さなコピーがあります。周期 3 のバルブの中心です。こうした「ミニ・マンデルブロ（ミニブロ）」はあらゆる拡大率で現れ、どれも少しずつ引き伸ばされ、ねじれています。

ミニ・マンデルブロを開く

非常に深いらせん

この表示の高さの半分は 4×10−30 で、拡大率はおよそ 3×1029 倍です。30 cm の画面で言えば、観測可能な宇宙のおよそ 100 倍の幅に引き伸ばしたマンデルブロ集合の絵へ、ズームして入り込むようなものです。通常の 64 ビットの数は約 16 桁しか表せないため、エクスプローラーは摂動法に切り替えます。

高いべき乗：マルチブロ集合

指数が 2 でなければならない理由はありません。べき乗 p を使うと、マルチブロ集合（Multibrot）と呼ばれる仲間たちが得られます。

zn+1=znp+c

テキスト表記：z → z^p + c

べき乗が整数のとき、図形は (p−1) 回の回転対称性を持ちます。3 次の集合なら丸い部分（ローブ）が 2 つ、4 次なら 3 つです。2.5 のように分数のべき乗では、zp の取りうる複数の値のうち 1 つをコンピューターが選ばなければなりません（主枝）。その選び方が負の実軸をまたぐところで飛ぶため、かすかな継ぎ目が残ります。エクスプローラーは、1.5 から 12 までの任意のべき乗を受け付けます。

べき乗 3 べき乗 4 べき乗 2.5

超深度ズームにはべき乗 2 が必要です。それ以外のべき乗では、エクスプローラーは通常の精度の限界でズームを止め、その旨をお知らせします。

エクスプローラーで見る
