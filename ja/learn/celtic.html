ケルト・フラクタル

数を 2 乗してから、その実部を正の側へ折りたたみます。できあがるのは、上下対称の、矢じり形のフラクタルです。

ルール

ケルト・フラクタルは、2 乗の前ではなく後に平面を折りたたみます。まず z をいつもどおり 2 乗し、次に実部だけの絶対値をとって虚部はそのままにし、最後に c を足します。

zn+1=|Re⁡(zn2)|+iIm⁡(zn2)+c

テキスト表記：z → |Re(z²)| + i·Im(z²) + c

実数の座標で、z=x+iy および c=a+ib と書くと、次のようになります。

xn+1=|xn2−yn2|+a,yn+1=2xnyn+b

テキスト表記：x' = |x² − y²| + a, y' = 2xy + b

マンデルブロ集合のルールと比べて変わるのは、x2−y2 を囲む 1 組の縦棒だけです。この折りたたみは、平面の左側に落ちたものをすべて右側へ折り返します。そのため、各ステップのあとの新しい実部は、a を下回ることがありません。

由来

このフラクタルには、これだと指させる創始者の論文がありません。バーニングシップと同じ時期に、フラクタルアートのコミュニティで育った、マンデルブロのルールの絶対値バリエーションの一族に属しています。名前も、そのコミュニティで生まれた愛称です。この折りたたみは解析的な写像ではないため、ドゥアディとハバードの古典的な理論はそのままでは使えず、この集合は主に、実際に眺めることで調べられています。

どこに注目するか

  • ハート形ではなく矢じり形。マンデルブロ集合のカージオイドは、なめらかな丸い輪郭です。ここでは主役の本体が、左側の平らな、右向きの矢じり形になり、さらに左のほうに、より小さな釣り鐘形の領域があります。
  • 木のような房。平らな縁の左側には、小さな木のように枝分かれする、小さなコピーの房があります。フィラメントのシェーディングを使うと、その細い輪郭がなぞれます。
  • 直線の縁をもつ扇形。右側では、色の帯が直線の縁をもつ扇形に分かれます。折りたたみがはっきり現れたものです。
  • 鏡の線。図は実軸について対称です。z と c をいっしょに共役にしても、ルールは変わらないからです。
  • 実軸。実数では x2 が負になることはないので、折りたたみは何も起こさず、ケルト・フラクタルは、マンデルブロ集合とまったく同じ −2 から 14 のあいだで実軸と交わります。
  • さまざまなべき乗。エクスプローラーは、1.5 から 12 までのどの指数でも、べき乗のあとに同じ折りたたみを適用します。パネルの形状セクションで設定してください。たとえばべき乗 3です。

ケルトのジュリア集合

c を固定して出発点を変えると、同じルールからケルトのジュリア集合が得られます。これは c=−0.95+0.24i の例です。

ちょっとした実験

最初の表示を開き、隅のジュリア集合のプレビューを見ながら、ポインターを矢じり形から釣り鐘形の領域までゆっくりドラッグしてみましょう。2 つの領域をまたぐとき、プレビューの雰囲気が変わります。続いて、シェーディングをフラット、フィラメント、レリーフと切り替えて、同じ境界が光を当てたときと当てないときでどう見えるかを確かめてください。

家族のよく似た点を探す

エクスプローラーにある 5 つのマンデルブロ系フラクタルは、折りたたみ方が違うだけの、同じ発想から生まれたものです。マンデルブロ集合、バーニングシップ、トライコーン、バッファローを順に開いて、実軸の同じ区間をそれぞれがどう扱うかを比べてみましょう。折りたたみがどこに入るかは、1 つの式にまとめた表に正確に示してあります。

エクスプローラーで見る

試してみましょう：点にカーソルを合わせて J キーを押すと、その点のケルトのジュリア集合が開きます。続けて C キーを押してカラーサイクルを始めてみてください。移り変わる色のおかげで、折りたたまれた構造を目で追いやすくなります。
