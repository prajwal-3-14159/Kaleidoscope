プライバシーポリシー

Kaleidoscope は、利用者の個人情報を収集しません。このページでは、それが具体的に何を意味するのかを、わかりやすく説明します。

最終更新日：2026年11月3日

要点

  • アクセス解析、広告、Cookie、ユーザーアカウント、そのほか一切のトラッキングを行っていません。
  • どこを拡大したか、どの画像を書き出したか、ベンチマークの結果がどうだったかといった情報が、運営者や第三者に送信されることはありません。
  • 一部の設定は、お使いのブラウザ内にだけ保存されます（下記参照）。いつでも削除できます。

運営者について

Kaleidoscope は、Kaleidoscope プロジェクト（以下「当プロジェクト」）が開発・運営する Web アプリケーションです。お問い合わせは、プロジェクトの GitHub リポジトリの Issues からお願いします。Issues は一般に公開されますので、個人情報は書き込まないでください。

サイトの配信方法

Kaleidoscope は静的な Web サイトです。ページ、スクリプト、画像、フォントはすべて通常のファイルであり、サーバー側のプログラムや独自のデータベースはありません。これらのファイルは、Microsoft のサービスである Azure Static Web Apps から HTTPS で配信されています。

ブラウザがこれらのファイルを取得する際、Microsoft のインフラでは、セキュリティや運用のために、IP アドレス、ブラウザのユーザーエージェント、アクセス日時、リクエストされた URL といった一般的なサーバーログが記録される場合があります。当プロジェクトはアクセス解析を行っておらず、ログを使って訪問者を特定したり追跡したりすることもありません。Microsoft によるデータの取り扱いについては、Microsoft のプライバシーに関する声明をご覧ください。

サイト自身のファイルに対するこうした通常のリクエストを除き、Kaleidoscope を使っている間にブラウザからサーバーへデータが送信されることはありません。

ブラウザ内に保存される情報

描画は、GPU と CPU のどちらを使う場合でも、すべてお使いの端末の中で行われます。表示している画面、書き出した画像、ベンチマークの実行内容がアップロードされることはありません。書き出した PNG 画像はブラウザ内で生成され、ダウンロードしたときにだけ端末に保存されます。

サイトは、Cookie ではなくブラウザの localStorage を使って、次の情報をお使いの端末に保存します。

キー保存される内容
kaleidoscope.lang選択した言語（英語または日本語）。どちらかの言語でページを閲覧したときにも保存され、エクスプローラーやページがお好みの言語で開くようになります。
kaleidoscope.bench.*ベンチマークの履歴と設定。スコア、実行日時、ブラウザが報告するグラフィックスデバイス（GPU）の名称、ベンチマークの設定が含まれます。お使いの端末で実行結果を見比べるために使われます。

これらのデータが端末の外に出ることはなく、当プロジェクトが見ることもできません。端末内で自分用の設定を覚えておくためだけに使うため、Cookie に関するバナーは表示していません。削除するには、ブラウザの「サイトデータの消去」（または「Cookie とサイトデータ」）の設定を使うか、ウィンドウを閉じると保存内容が破棄されるプライベートウィンドウ（シークレットモード）をご利用ください。

共有リンク

エクスプローラーのアドレスには、現在の表示内容（フラクタルの種類、中心座標、拡大率、べき乗、パレットなど）が # 以降に含まれています。そのため、表示をブックマークしたり、ほかの人に送ったりできます。ブラウザはページを要求するとき、# 以降をサーバーに送信しません。また、リンクにはあなた自身に関する情報は含まれていないため、リンクを共有しても伝わるのはこれらの数値だけです。ただし、チャットや SNS、メールにリンクを貼り付けた場合、そのサービスには貼り付けたリンクが見えます。

フォントと外部コンテンツ

書体（Outfit と Space Grotesk）はこのサイト自身が配信しているため、ページを表示するために Google Fonts などの第三者へ接続することはありません。外部のスクリプト、トラッカー、広告、アクセス解析、埋め込みコンテンツも読み込みません。

GitHub など外部サイトへのリンクは、それぞれ独自のプライバシーポリシーを持つサービスにつながります。それらについて当プロジェクトは責任を負わず、リンクは推奨を意味するものでもありません。

ベンチマークと動画の録画

ベンチマークは端末上だけで実行され、結果は上記のとおりローカルストレージにのみ保存されます。ベンチマークの様子を、オプションで動画に録画することもできます。録画はブラウザの標準機能（MediaRecorder API）で行われ、端末上に保持されます。ご自身でダウンロードを選んだ場合にだけファイルとして保存され、アップロードされることはありません。

お子様について

Kaleidoscope は 13 歳未満のお子様を対象としていません。そもそも、このサイトは誰からも個人情報を収集しないため、お子様の情報を収集・保管・削除する対象もありません。

利用者の権利とお問い合わせ

当プロジェクトは利用者に関する個人情報を保有していないため、開示、訂正、書き出し、削除などの対応の対象となるデータがありません。端末の外にある、ご訪問に関連するデータは、上記の Microsoft による一般的なサーバーログだけです。それについてのご請求は、Microsoft のプライバシーに関する声明をご確認ください。本ポリシーについてご不明な点があれば、お気軽に GitHub で Issue を作成してください。

ポリシーの変更

データの扱いが変わる機能が追加された場合などに、本ポリシーを変更することがあります。変更した際は、ページ上部の最終更新日を更新します。過去の版は、GitHub 上のプロジェクトの公開履歴で確認できます。
