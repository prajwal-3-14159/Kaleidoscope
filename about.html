About Kaleidoscope

Kaleidoscope, also known as Quantum Fractals, is a fractal explorer that runs entirely in your web browser. Pan, zoom and fly through the Mandelbrot set and its relatives, all the way down to magnifications of about 10300.

Open the explorer Learn about fractals

What it is

Kaleidoscope is a static website: no installation, no account and no server doing the work. Your own device draws every image, either on its graphics card with WebGL2 or on its processor with a pool of background workers. It is built for exploring, so you can drag, scroll, pinch and double-click your way into a fractal, then export what you find.

  • Six fractals. The Mandelbrot set, Burning Ship, Tricorn, Celtic and Buffalo, each with a Julia variant, plus the Sierpiński triangle. Powers from 1.5 to 12 are supported.
  • Two engines. A GPU engine (WebGL2 fragment shaders) and a CPU engine (64-bit floating point across Web Workers).
  • Deep zoom to about 10300. For power-2 fractals, Kaleidoscope switches to perturbation theory with rebasing, using high-precision reference orbits, so images stay correct far beyond the reach of ordinary 32-bit and 64-bit numbers.
  • Colour. Eight palettes interpolated in the OKLab colour space, smooth colouring, distance-estimate filaments, 3D relief lighting and optional animated colour cycling.
  • Progressive rendering. A quick preview while you move, then sub-pixel samples accumulate for smooth anti-aliased detail.
  • PNG export at up to 4× resolution, rendered in tiles on your device.
  • Guided tour of notable places, with animated flights between them.
  • Benchmark with fixed scenes, to see how your device performs.
  • Shareable links. The current view is stored in the address, so you can bookmark it or send it to a friend.
  • English and Japanese.

To learn what you are looking at, read the Learn section: articles on each fractal, a plain-language account of how the deep zoom works, and a glossary.

How it is built

Kaleidoscope is plain HTML, CSS and JavaScript using native ES modules, with no build step and no framework. It is hosted as static files on Azure Static Web Apps. The source code is published on GitHub; licence terms are those stated in the repository.

Credits

  • Perturbation theory for deep zooming follows K. I. Martin’s 2013 note “superfractalthing”, which showed how to compute a single high-precision reference orbit and iterate every pixel as a small difference from it.
  • Rebasing, which prevents glitches in perturbed images, follows the technique described by Zhuoran in 2021.
  • OKLab, the perceptual colour space used to blend palettes, was designed by Björn Ottosson (bottosson.github.io).
  • Fonts. Outfit by Rodrigo Fuenzalida and Space Grotesk by Florian Karsten, both under the SIL Open Font License 1.1 (licence, licence).
  • Hosting by Azure Static Web Apps (Microsoft).
  • The mathematics of these fractals is the work of many mathematicians over decades; the Learn pages describe it in simple terms.

Accessibility statement

We want Kaleidoscope to be usable by as many people as possible. We have not had a formal accessibility audit, so this is an honest description of where things stand.

What works

  • Keyboard. The explorer can be controlled from the keyboard, and the side panel uses standard buttons, sliders and switches that you can reach with Tab. Dialogs are native and close with Esc.
  • Reduced motion. If your system asks for reduced motion, interface animations and transitions are effectively switched off, here and in the explorer, and the benchmark score appears without its count-up animation. Colour cycling is off by default.
  • Dark interface. The interface is dark with light text, and these pages use a responsive layout that works on small screens and with browser zoom.
  • Language. Everything is available in English and Japanese, and each page declares its language.

Known limits

  • A fractal is a picture. The image itself has no text alternative; only the readout of position, zoom and iteration count is text.
  • Choosing a point for the Julia preview depends on the pointer position, and some actions, such as pinch zoom, are touch or mouse gestures. Panning and zooming also work from the keyboard.
  • Colour cycling and the benchmark can show fast-changing, high-contrast patterns; see the photosensitivity warning.
  • There is no light theme, and the explorer has not been tested extensively with screen readers.

If you run into a barrier, please tell us on GitHub and we will do our best to improve it.
