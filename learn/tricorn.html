The Tricorn (Mandelbar)

Flip the number across the real axis before squaring and the familiar heart of the Mandelbrot set becomes a three-cornered hat, the tricorn.

The rule

The Tricorn changes the Mandelbrot recipe in a different way. Instead of folding the numbers, it flips them: before squaring, replace z by its complex conjugate, which mirrors the number across the real axis (the imaginary part changes sign).

zn+1=z¯n2+c

Plain text: z → conj(z)² + c

In real coordinates, with z=x+iy and c=a+ib, one step reads

xn+1=xn2−yn2+a,yn+1=−2xnyn+b

Plain text: x' = x² − y² + a, y' = −2xy + b

The only difference from the Mandelbrot rule is the minus sign in front of 2xy. That one sign turns the familiar heart and bulbs into a three-armed, three-cornered shape: the "tricorn", or three-cornered hat.

A short history

The set was studied by W. D. Crowe, R. Hasson, P. J. Rippon and P. E. D. Strain-Clark in 1989, who called it the Mandelbar set. John Milnor later met it again while studying real cubic polynomials and gave it the name tricorn. Both names are in use today.

Why three corners

Conjugation reverses the direction of rotation, so one step of the Tricorn rule is not an ordinary "analytic" map, and the usual machinery for the Mandelbrot set does not apply directly. A neat trick rescues part of the story: apply the rule twice and the two conjugations cancel. The result is an ordinary polynomial of degree 4.

z↦(z2+c¯)2+c

Plain text: z → (z² + conj(c))² + c (two steps combined)

Turning the plane by a third of a full turn (120°) maps c to another parameter that gives the same picture, which is where the three-fold symmetry comes from. The Tricorn is also mirror-symmetric about the real axis, so overall it looks the same after any of six flips and turns, the symmetries of a triangle.

What to look for

  • Three arms spaced 120 degrees apart, each ending in a small round bulb. One lies along the negative real axis.
  • Bulbs and spikes hanging from the edge of the main body, repeating the three-way pattern.
  • Tiny copies of the whole shape, tilted and stretched, deeper in. Zoom around the edges to look for them.
  • The real axis. Conjugating a real number does nothing, so along the real axis the Tricorn and the Mandelbrot set agree.

As for the Mandelbrot set, the Tricorn is the set of parameters c whose Julia set is connected, and the orbit of the critical point 0 decides which side of the line a given c falls on.

You can also change the exponent. With z↦z¯d+c and a whole number d, the picture has (d+1)-fold rotational symmetry. These shapes are called multicorns. Set the power in the Shape section of the panel and see for yourself.
