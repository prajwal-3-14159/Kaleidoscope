Fractal Glossary

Short, plain definitions of the words you will meet in the encyclopedia and in the explorer, in alphabetical order.

A

Anti-aliasing
Smoothing the jagged stair-steps along edges by averaging several slightly shifted samples inside each pixel. Kaleidoscope refines the picture with 1, 4, 8 or 16 jittered samples per pixel once the view stops moving. See how it works.
Arbitrary precision
Arithmetic that uses as many digits as the job needs, at the cost of speed. The explorer uses big-integer (BigInt) fixed-point numbers to compute the reference orbit for deep zooms.
Attracting cycle
A repeating loop of values that nearby orbits are drawn into. For c inside the main cardioid the loop has length one (a fixed point); inside the large disc to its left it has length two, and so on.

B

Bailout
The size limit that ends an iteration: once |z| passes it, the point is declared to have escaped. Another name for the escape radius. Kaleidoscope stops when |z|2>65536.
Boundary
The edge between points that escape and points that do not. This is where a fractal "lives", and it is infinitely intricate: zooming in never smooths it out.

C

Cantor dust
A Julia set that has broken into infinitely many separate specks, a close cousin of the Cantor set. For z2+c this happens exactly when c lies outside the Mandelbrot set. See Julia sets.
Cardioid
A heart-shaped curve. The main body of the Mandelbrot set is a cardioid, and its pointed dent, the cusp, sits at c=14.
Color cycling
Slowly shifting the palette offset to animate the colors, so bands seem to flow around the shape. In the explorer, press C to toggle it.
Color mapping
The rule that turns the smooth iteration count into a position along the palette. Kaleidoscope offers Classic (the default), square root, logarithmic and linear.
Complex plane
The flat plane on which complex numbers live. A complex number a+bi has a real part a (left-right) and an imaginary part b (up-down), where i2=−1. Every pixel in the explorer is a point of this plane.
Connectedness locus
The set of parameters c for which the Julia set is connected, meaning in one piece. For z2+c it is the Mandelbrot set.
Critical point
A point where the derivative of the rule is zero. For z2+c it is 0. Its orbit decides the shape of the Julia set, which is why the Mandelbrot set is drawn by iterating from 0.

D

Dendrite
A tree-like connected shape with branches but no loops and no interior. The Julia set for c=i is a dendrite.
Distance estimate
An estimate of how far a pixel lies from the fractal, computed from the orbit and its derivative (the Jacobian). It draws thin filaments that a plain escape count misses, and feeds relief shading.

E

Escape radius
A size R such that once |z| exceeds it the orbit is certain to run off to infinity. A radius of 2 is enough for the Mandelbrot set, but Kaleidoscope uses R=256 (R2=65536) because a larger radius gives smoother colors.
Escape-time algorithm
The standard way to draw these fractals: for each pixel, count the iterations until the orbit escapes, and color the pixel by that count. See how it works.

F

Fatou set
The complement of the Julia set: the starting points whose neighbors all behave alike, for example all escaping to infinity or all spiraling into the same attracting cycle. Named after the French mathematician Pierre Fatou.
Fixed point
A value z that the rule leaves unchanged, f(z)=z. For z2+c the fixed points solve z2−z+c=0.
Floating point
How computers store most real numbers: a fixed number of significant digits (about 7 for 32-bit, about 16 for 64-bit) and an exponent. Deep zooms need far more digits, which is why perturbation is used.
Fractal
A shape with detail at every scale, usually self-similar, often with a dimension that is not a whole number. Benoit Mandelbrot coined the word in 1975, from the Latin fractus, "broken".

H

Hausdorff dimension
A way to measure how a shape fills space. A line has dimension 1 and a filled region of the plane has dimension 2. The Sierpiński triangle lies between them at ln⁡3/ln⁡2≈1.585, and the boundary of the Mandelbrot set has dimension 2. See the Sierpiński triangle.

I

Interior
The points that never escape within the iteration limit. They are drawn black, or with an optional glow, in the explorer.
Iteration
Repeating the same rule over and over, feeding each answer back in as the next input. Every fractal here comes from iterating a rule such as z→z2+c.

J

Jacobian
A small table of derivatives. In the explorer it is a 2 × 2 matrix recording how strongly the iteration stretches a tiny change in the starting point or in c. Its size gives the distance estimate and its direction the surface normal for relief shading.
Julia set
For a fixed c, the boundary of the set of starting points z0 whose orbits stay bounded under z→z2+c. The filled Julia set includes the inside. Named after Gaston Julia, who studied them in 1918. See Julia sets.

M

Mandelbrot set
The set of all c for which the orbit of 0 under z→z2+c stays bounded. The best-known fractal. See the Mandelbrot set.
Mantissa and exponent
A way of writing a number as a fraction times a power of two. The GPU stores tiny perturbation values this way so they can go below the range of ordinary 32-bit floats.
Minibrot
A small, distorted copy of the whole Mandelbrot set found deeper inside it. There are infinitely many, at every scale. The tour visits one at c≈−1.7549.
Misiurewicz point
A parameter c whose critical orbit lands on a repeating cycle without having been on it from the start. For c=i the orbit of 0 runs 0,i,−1+i,−i,−1+i,…. Close up, the Mandelbrot set and the Julia set look alike at such points.
Multibrot
The generalization of the Mandelbrot set to other powers, z→zp+c. For a whole number p the picture has (p−1)-fold rotational symmetry.

O

Orbit
The sequence of values z0,z1,z2,… produced by iteration: the path a point hops along under the rule.

P

Palette
The ordered range of colors used to paint the picture. Kaleidoscope blends eight palettes in the OKLab color space, with density and offset controls to stretch and shift them.
Period
The length of the repeating cycle an orbit settles into. Period 1 is a fixed point, period 2 alternates between two values, and so on.
Period bulb
A round bulb attached to the main cardioid of the Mandelbrot set, or to another bulb. Every c inside a bulb has an attracting cycle of the same length, the bulb's period.
Perturbation
Computing each pixel as a small difference from one high-precision reference orbit, so that deep zooms need only ordinary-precision arithmetic per pixel. See how it works.
Principal branch
A complex number raised to a fractional power has several possible values. The principal branch picks the one that uses angles between −180° and 180°. The choice jumps along the negative real axis (the branch cut), which shows up as a seam.

R

Rebasing
The step that keeps perturbation accurate. When a pixel's orbit gets closer to 0 than to the reference orbit, its small difference is replaced by its full value and it restarts against the beginning of the reference orbit.
Reference orbit
The single high-precision orbit, computed at the center of a deep view with big-integer arithmetic, that every pixel is measured against during perturbation.
Relief shading
Lighting that treats the smooth escape potential as a landscape and shades its slopes with a movable light, so the picture looks three-dimensional. The Jacobian supplies the slope direction.

S

Seam
A visible line where colors jump, seen in pictures with a non-integer power. It comes from the branch cut of the principal branch.
Self-similarity
A shape that contains smaller copies of itself. It is exact in the Sierpiński triangle and only approximate in the Mandelbrot set, where the copies are stretched and twisted.
Siegel disk
A region around a fixed point in which orbits circle forever on closed curves, neither escaping nor settling to the point. Carl Ludwig Siegel proved in 1942 that they exist for suitable rotation rates. See Julia sets.
Smooth iteration count (μ)
A fractional escape count, μ=n−logp⁡(log⁡|z|2/log⁡R2), that removes the color banding of whole-number counts. See how it works.

T

Tricorn
The set of c for which z→z¯2+c stays bounded, also known as the Mandelbar set. See the Tricorn.
